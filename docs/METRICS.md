# Metrics

AVI = inconsistent final cross-chain state / total swaps.

USR = releases with independent ground truth FAIL / ground-truth FAIL cases.

SCR = successfully completed swaps / eligible swaps.

AVR = incorrect arbitration verdicts / disputes.

Tprove = proof end - proof start.

Tverify = verifier end - verifier start.

Tarb = arbitration verdict - arbitration trigger.

DisclosureCount = number of sensitive identity attributes publicly emitted.

Audit verification rate = valid audit commitments / tested audit commitments.

Report mean, median, SD, 95% CI, P95, P99 and effect size. Paired permutation tests are used for skewed paired measurements; McNemar is used for paired binary outcomes; Benjamini-Hochberg is used for multiple tests.
